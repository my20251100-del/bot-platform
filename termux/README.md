# 📱 تشغيل محرك البوت على Termux (أندرويد 24/7)

هذا المجلد يحتوي على كل ما يلزم لتشغيل محرك البوت خفيفاً وبدون متطلبات معقدة على هاتف أندرويد عبر تطبيق **Termux**.

---

### ⚠️ ملاحظة مهمة جداً (لمنع تعارض الربط):
**لا تقم بتشغيل المحرك على الكمبيوتر وعلى هاتف Termux في نفس الوقت بنفس قاعدة البيانات.**
- إذا كنت تشغل البوت من Termux على هاتفك: تأكد من إيقاف الخدمة على الكمبيوتر (`sudo systemctl stop bot-engine`).
- إذا كنت تشغله من الكمبيوتر: لا تشغل `start.sh` على Termux.
- تشغيلهما معاً يسبب تعارضاً (Conflict 440) في واتساب ويلغي كود الاقتران.

---

### 🚀 خطوات التشغيل لأول مرة على Termux:

1. ثبت المتطلبات الأساسية في Termux:
```bash
pkg update -y && pkg install -y nodejs git ffmpeg
```

2. ادخل لمجلد `termux`:
```bash
cd ~/bot-platform/termux
```

3. شغّل السكربت التلقائي:
```bash
./start.sh
```
- سيقوم السكربت بتثبيت الحزم تلقائياً ومنع إغلاق التطبيق في الخلفية (`termux-wake-lock`).
- المحرك سيتصل بقاعدة البيانات مباشرة ويطلب أكواد الاقتران ويدير البوت 24 ساعة.

---

### 🔄 التحديث السريع بعد كل إضافة:
كل ما عليك فعله لتحديث الكود عند إضافة مميزات جديدة:
```bash
./update.sh
```
ثم شغّل المحرك:
```bash
./start.sh
```
